# Proyecto: Sistema de reservas para barbería

## Contexto
Proyecto de portafolio y base para un producto que venderé a negocios locales.
Mi nivel: sé PHP, SQL y desarrollo móvil. Next.js y TypeScript los estoy aprendiendo.

## Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Supabase (Postgres + Auth) — se agregará más adelante
- Deploy en Vercel

## Cómo quiero que trabajes conmigo
- Antes de escribir código, explícame el plan en pasos y espera mi visto bueno.
- Trabaja en piezas pequeñas: una funcionalidad a la vez, no el proyecto completo.
- Cuando uses algo de Next.js o TypeScript que yo no domino, explícame en 2-3 líneas
  qué hace y por qué, en español, ANTES del código.
- No introduzcas librerías nuevas sin decírmelo y justificarlo.
- Si algo lo puedo resolver con lo que ya está en el proyecto, no agregues dependencias.

## Convenciones
- Comentarios y textos de UI en español; nombres de variables y funciones en inglés.
- Nunca poner llaves o secretos en el código: siempre en .env.local.
- Cada cambio debe dejar el proyecto corriendo con `npm run dev`.

## Comandos
- `npm run dev` — servidor local
- `npm run build` — verificar que compila antes de hacer commit
- `npm run lint` — revisar errores de estilo
